# SQL 血缘平台前端设计

## 用户场景

本项目面向数据治理平台的四类高频操作：

1. **发现表与资产**：分析师通过全局搜索找到 Dataset、Job、Dashboard、ML Model，并在结果中看到迷你血缘预览。
2. **评估变更影响**：数据开发模拟字段类型、字段命名或口径变更，递归查看受影响的下游实体。
3. **查询血缘上下游**：治理 Owner 在 Canvas DAG 中逐层展开上下游，避免全量渲染造成性能问题。
4. **字段级定位问题**：从看板指标下钻到表字段映射，查看转换表达式并确认源字段。

## 页面体系

| 页面 | 目标 | 首版实现 |
| --- | --- | --- |
| 首页 | 全局搜索、热门实体、最近访问 | 全局搜索框、类型分组、迷你血缘预览 |
| 血缘图页 | Canvas 交互式 DAG 图 | DAG 卡片节点、逐层展开说明、字段级下钻按钮 |
| 实体详情页 | Schema / Lineage / Usage / Queries | 右侧滑出面板模拟多 Tab，不跳转页面 |
| 影响分析页 | 变更模拟与递归影响高亮 | `ods_order.amount` 变更影响列表与 Owner 通知按钮 |

## 组件状态

| 状态 | 页面表现 | 用户动作 |
| --- | --- | --- |
| 加载中 | 骨架屏与 Canvas 节点占位 | 搜索框仍可输入 |
| 空数据 | 提示没有匹配实体 | 建议改用库名、表名或 Owner 搜索 |
| 错误 | 展示错误说明与重试入口 | 保留查询条件和展开层级 |
| 正常 | 展示分组结果、DAG、右侧详情、影响列表 | 可继续下钻、模拟变更、通知 Owner |

## 列级血缘钻取路径

首版内置示例路径：

```text
ads_revenue_dashboard.gmv
  -> dws_trade_summary.gmv
  -> dwd_order_detail.pay_amount
  -> ods_order.amount
```

用户路径：

```text
看板节点
  -> 右侧 Slide-out
  -> Schema Tab
  -> 选择 gmv 字段
  -> 展示上游字段映射链路与 transform 表达式
```

## 技术结构

- `src/data/lineageModel.ts`：血缘实体、字段映射、搜索分组、字段追踪、递归影响分析。
- `src/App.tsx`：单页原型，集中展示设计 Skill 要求的全部页面模块。
- `@xyflow/react`：作为后续真实 Canvas DAG 的 React Flow 渲染依赖。
- `@apollo/client` 与 `graphql`：作为后续接入 GraphQL 深层嵌套血缘数据的基础依赖。
- `vitest` 与 Testing Library：覆盖领域模型和页面关键行为。
